## 三、 問答題

### 問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？
**答：** 因為 `"4"` 在 Python 中是字串（`str`）型別，Python 無法直接將金額數值除以字串進行數學除法運算，會引發型別錯誤（TypeError）。因此必須先用 `int()` 將其轉成整數，才能正確進行分攤計算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**答：** 
- **計算結果：** 應付總額會變成 1,210 元。（計算方式：$(1,200 - 100) \times 1.10 = 1,210$）
- **為什麼不同：** 因為餐廳服務費的常規計算標準是以「原始餐費（未折價前）」為基準來收取 10% 服務費。如果先扣折價券會縮小服務費的計算基數，導致總金額與正統規定不符。
